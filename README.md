# Diu-food-court-simulation
Desmos-based 2D design of a DIU Food Court scene, featuring the DIU building, food stalls, road, trees, bushes, tables, chairs, and pedestrians. This design serves as the visual reference and layout plan for the final OpenGL Food Court Simulation.
